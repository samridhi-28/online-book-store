# 📚 Online Bookstore SQL Data Analytics Project

## 📌 Project Overview
This project focuses on designing and querying a relational database for an **Online Bookstore** using **PostgreSQL**. It covers end-to-end database operations, including schema setup, data management, and business logic execution.

## 🛠️ Key SQL Skills & Concepts Demonstrated
- **Database Architecture:** Table creation, data types, primary/foreign key relationships.
- **Data Aggregation & Analysis:** `GROUP BY`, `SUM`, `AVG`, `COUNT`.
- **Date Handling & Formatting:** Date arithmetic and timestamp functions.
- **Advanced Querying:** Filtering, ordering, and multi-table joins.

## 📂 Repository Structure
- `schema.sql` - Table creation scripts and database structure.
- `queries.sql` - Business analytics queries and problem-solving scripts.
- `data/` - Sample dataset / CSV files used for ingestion.
